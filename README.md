# Taschenrechner

Einfacher Taschenrechner mit HTML, CSS und JavaScript. Schulprojekt im Rahmen der Umschulung zum Fachinformatiker für Systemintegration.

## Funktionen

- Addition, Subtraktion, Multiplikation und Division
- Dezimalzahlen
- Prozent (%)
- Letzte Ziffer löschen (⌫) und alles löschen (C)
- Fehlermeldung bei Division durch null
- Bedienung mit der Tastatur

## Starten

Die Datei `index.html` in einem beliebigen Browser öffnen.

## Tastatur

| Taste             | Aktion            |
|-------------------|-------------------|
| `0`–`9`           | Ziffern           |
| `+` `-` `*` `/`   | Rechenarten       |
| `.` oder `,`      | Komma             |
| `Enter` oder `=`  | Ergebnis          |
| `Backspace`       | Ziffer löschen    |
| `Esc`             | alles löschen     |

## Dateien

- `index.html` – Aufbau der Seite
- `style.css` – Gestaltung
- `script.js` – Logik des Taschenrechners
